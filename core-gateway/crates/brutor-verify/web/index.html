Evidence verifier

Checks a Brutor evidence bundle or action record entirely in this browser: nothing is uploaded and no network request is made. Each check below states only what it established for the files you supplied. Conclusions about the system the evidence describes are yours to draw.

Evidence bundle (JSON) Drop a file here or click to choose. A bundle API response is accepted too.
Trusted keys (optional) A /.well-known/brutor-evidence-keys.json document. Without one, signatures are checked under the keys the statements name.
Action record (JSON) Drop a file here or click to choose.
Trusted keys (optional) Shared with the Bundle tab.
