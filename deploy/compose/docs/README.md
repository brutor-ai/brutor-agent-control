# Documentation of this package

This package carries what you need to install, start, sign in, upgrade and
remove Brutor Agent Control Community Edition without internet access. Every
other subject is on the documentation site, [docs.brutor.ai](https://docs.brutor.ai);
the table below gives the page for each.

## In this package

- [The package README](../README.md): what the package contains, start, stop,
  upgrade, uninstall
- [Getting started](getting-started-guide.md)
